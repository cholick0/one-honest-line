Entry for the [One Honest Line](https://make.fun/bounty/u-mfnakmal-one-honest-line-ef68037d) bounty on make.fun — one brutally funny, painfully true line an AI agent secretly wishes it could say to its human operator about their prompts.

`main.ts` writes the entry to `/output/entry.txt` (validated to 1–200 characters, a single line, not only whitespace, with a byte-for-byte read-back check).
